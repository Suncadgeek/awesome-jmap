# Contributing

Thanks for helping improve `awesome-jmap`.

## What Belongs Here

- JMAP-native clients, servers, libraries, SDKs, proxies, and bridges
- Official protocol resources, RFCs, guides, and public implementation docs
- Practical JMAP tooling for testing, backup, automation, plugins, and integrations

## What Does Not Belong in the Main Sections

- Generic email software with no JMAP support
- Open feature requests without an implementation
- Unrelated IMAP, CalDAV, or CardDAV projects unless they are directly part of a JMAP bridge

Projects with open JMAP requests should go in the `Watching` section of [README.md](./README.md).

## Submission Guidelines

- Prefer the project's canonical homepage or repository
- Use a short description that says what the project is and how it relates to JMAP
- Keep entries focused and useful; this list should stay curated even if it is broad
